# Shivanya Admin

Frontend-only administration and analytics workspace for the Shivanya ecosystem.

## Scope

- Next.js + TypeScript
- Shivanya UI and Shell
- Organizations, users, applications, activity, events and pages
- Dashboard and analytics dimensions
- Local frontend data store for V1
- Separate analytics adapter designed to move into shivanya-sdk later
- Vitest unit tests

This repository intentionally has no backend. Backend analytics and product APIs can be connected later without replacing the page architecture.
